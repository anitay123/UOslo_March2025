Overview of the github files:
1) "Developing ML models": Development and evaluation of RF, SVM, AdaBoost, and LightGBM models for sleep–wake classification, including oversampling techniques (SMOTE, ADASYN) and hyperparameter tuning.
2) "Preprocessing pipeline": Initial preprocessing workflow for physiological signal preparation prior to classification, including filtering, feature extraction, and data preparation.
3) "Classification stages": Evaluation of ML and DL models across binary (Sleep/Wake), 3-class (Wake, NREM, REM), and 5-class (Wake, N1, N2, N3, REM) classification tasks, including sensor modality comparisons and performance metrics such as accuracy, F1-score, and Cohen’s kappa.
